Project Overview

  1. The AI Stroke Prediction System is a Machine Learning-based healthcare project designed to predict the risk of stroke using patient health and demographic information.
  2. The system analyzes important factors such as age, hypertension, heart disease, marital status, work type, residence type, and smoking status to estimate stroke probability.
  3. The project also addresses the challenge of imbalanced healthcare data using SMOTENC and evaluates multiple Machine Learning algorithms to identify an effective prediction model.

Problem Statement

  1. Stroke is a serious health condition, and early identification of individuals who may be at higher risk can support timely medical attention.
  2. However, healthcare datasets often contain imbalanced data, where the number of non-stroke cases is significantly higher than stroke cases. This can make Machine Learning models biased toward the majority class.
  3. The project aims to develop a Machine Learning model that can accurately predict stroke risk while addressing the challenges posed by imbalanced data.
  4. The problem is to develop a Machine Learning system that can:
    • Analyze healthcare and demographic factors.
    • Handle imbalanced stroke datasets.
    • Identify patterns associated with stroke risk.
    • Generate a probability-based prediction.
    • Provide an understandable risk classification.

Solution

  1. The proposed solution is a comprehensive Machine Learning pipeline that processes healthcare data to predict stroke risk.
  2. The system performs data preprocessing, feature transformation, and handles class imbalance using SMOTENC.
  3. Multiple Machine Learning models are trained and evaluated using classification metrics to identify the best-performing model.
  4. The final model can accept patient information and generate a stroke probability along with a risk category.

Objectives

  • Develop an AI-based stroke-risk prediction system.
  • Preprocess and clean healthcare data.
  • Handle class imbalance using SMOTENC.
  • Train and compare multiple Machine Learning algorithms.
  • Evaluate models using appropriate classification metrics.
  • Generate probability-based predictions.
