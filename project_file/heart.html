Heart Disease Risk Prediction

Machine Learning Project

Project Overview

  1. Heart Disease Risk Prediction is a machine learning–based web application designed to estimate an individual's risk of heart disease using important health and clinical parameters.
  2. The project uses a Random Forest Classification model with hyperparameter tuning to analyze patient-related features and generate a risk prediction.
  3. The trained machine learning model is integrated with a Flask web application, allowing users to enter their health information through an interactive interface and receive a predicted risk category.
  4. The application supports both Normal User and Clinical User input modes.

Problem Statement

  1. Heart disease is influenced by multiple factors such as age, blood pressure, cholesterol, chest pain, heart rate, exercise-related symptoms, and ECG-related indicators.
  2. Traditional assessment can require analyzing several parameters together, which can be difficult for users without technical or medical expertise.
  3. The problem is to develop a machine learning system that can:
    • Analyze multiple cardiovascular health indicators.
    • Identify patterns associated with heart disease.
    • Predict the likelihood of heart disease from user-provided data.
    • Present the prediction through a simple and accessible web interface.

Solution

  1. The project solves this problem by building a complete machine learning pipeline.
  2. The dataset is first cleaned by handling missing values and duplicate records. Relevant health features are then separated from the target variable.
  3. The data is divided into training and testing sets using an 80/20 stratified split.
  4. The features are standardized using StandardScaler, after which a Random Forest Classifier is trained. GridSearchCV with 5-fold Stratified Cross-Validation is used to identify suitable model hyperparameters based on ROC-AUC performance.
  5. The trained model and scaler are saved and integrated into a Flask application. Users can enter their health parameters and receive a risk prediction through the web interface.

Objectives

  • Develop a machine learning model for heart disease risk prediction.
  • Perform data cleaning and preprocessing.
  • Identify relevant cardiovascular health features.
  • Train and optimize a Random Forest classification model.
  • Evaluate model performance using multiple classification metrics.
  • Build an interactive Flask-based web application.
  • Provide an easy-to-understand risk classification.
  • Create a foundation for future healthcare analytics and AI enhancements.
